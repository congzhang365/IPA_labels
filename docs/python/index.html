A gentle, example-led introduction for researchers who are comfortable with Python basics but are new to this package.

Python manual

Reading route: run the first example, learn the five groups, then choose either lookup, feature, or inventory work. You do not need to memorise the whole database.

Before the technical details

Think of ipa_labels as a box of information cards. Each card describes one IPA symbol. The card for p tells you what kind of sound it is and gives you its different writing and coding systems.

The symbol is the thing you are looking up. A group is a section on its card. So p.label.place means: “on the card for p, open the label section and show me the place of articulation”.

You do not need to learn every field before starting. Ask one small question first, then explore the other sections of the same record.

1. Install and make a first query

Install the current version directly from GitHub:

py -m pip install "git+https://github.com/congzhang365/IPA_labels.git#subdirectory=python_package"

Now ask for the record for p:

import ipa_labels

p = ipa_labels.get("p")
print(p.symbol.ipa)
print(p.label.full)

The first line prints the symbol. The second gives a readable description: voiceless bilabial plosive.

# Codes

# Labels

p.label.place
p.label.manner

# Names
p.description.ipa_name
p.description.unicode_name

Some values are unavailable for some symbols. The structured Python interface represents those as None. For example, a vowel normally has no consonant place.

4. Vowels and consonants

vowel = ipa_labels.get("ɘ")
print(vowel.label.height)       # close-mid
print(vowel.label.closeness)    # close-mid (alias)
print(vowel.label.frontness)    # central
print(vowel.label.roundedness)  # unrounded

consonant = ipa_labels.get("p")
print(consonant.label.voicing)  # voiceless
print(consonant.label.place)    # bilabial
print(consonant.label.manner)   # plosive

closeness and openness are aliases for height; backness is an alias for frontness.

5. Find several symbols

Use lookup() when you know the field you want. It returns a list because more than one symbol may match.

matches = ipa_labels.lookup(
    type="consonant",
    place="bilabial",
    fields=["symbol", "voicing", "manner"]
)

for match in matches:
    print(match)

Use fields="symbol" when you want a simple list. Grouped criteria are also supported:

ipa_labels.lookup(label={"place": "bilabial"}, fields="symbol")
ipa_labels.lookup(code={"unicode": "U+0070"}, fields="symbol")

6. PHOIBLE features

Labels and features answer different questions. p.label.place is a readable IPA label; p.features.labial is a structured PHOIBLE feature value. Use labels when you want a description for a person to read, and features when you want values to compare or analyse in code.

p = ipa_labels.get("p")
for name in ["consonantal", "sonorant", "continuant", "nasal", "labial"]:
    print(name, p.features[name])

Feature values are normally True, False, or None when PHOIBLE does not provide a value.

7. Language inventories

An inventory is a record of the sounds reported for a particular language or doculect. The function returns a list because one language can have several records from different sources. Each record retains its own language, doculect, ISO code, Glottocode, source, URL, inventory ID, and segment list.

english = ipa_labels.inventory(iso639_3="eng")

for inv in english:
    print(inv["inventory_id"], inv["language"], inv["doculect"])
    print(inv["iso639_3"], inv["glottocode"], inv["source"])
    for segment in inv["segments"]:
        print(segment["symbol"], segment["marginal"])

Other selectors are language=, glottocode=, and inventory_id=.

8. Keep the older API while you learn

ipa_labels.get("p", "place")
ipa_labels.lookup(place="bilabial")
ipa_labels.values("place", type="consonant", unique=True)
ipa_labels.query("voiced bilabial plosive", fields="symbol")
