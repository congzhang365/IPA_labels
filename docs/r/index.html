A gentle, example-led introduction for researchers using RStudio or R scripts to work with IPA data.

R manual

Reading route: copy the first example into RStudio, inspect the nested list with str(), then move on to searches and inventories.

Before the technical details

Think of ipa_labels as a box of information cards. Each card describes one IPA symbol. The card for p tells you what kind of sound it is and gives you its different writing and coding systems.

The symbol is the thing you are looking up. A group is a section on its card. In R, p$label$place means: “on the card for p, open the label section and show me the place of articulation”.

You do not need to learn every field before starting. Ask one small question first, then explore the other sections of the same record.

1. Install and load

install.packages("jsonlite")
remotes::install_local("r_package/ipa.labels")

library(ipa.labels)

For a local checkout, replace the path with the full path to the R package directory.

2. Make a first query

p <- ipaget("p")

p$symbol$ipa
p$label$full

R uses a nested list for a structured record. The $ operator moves from the record to a group and then to a field.

3. The five groups

5. Vowels and consonants

vowel <- ipaget("ɘ")
vowel$label$height
vowel$label$closeness
vowel$label$frontness
vowel$label$roundedness

consonant <- ipaget("p")
consonant$label$voicing
consonant$label$place
consonant$label$manner

closeness and openness are aliases for height; backness is an alias for frontness.

6. Search for many symbols

ipalookup() returns a data frame. Use fields to keep only the columns you need.

bilabials <- ipalookup(
  type = "consonant",
  place = "bilabial",
  fields = c("symbol", "voicing", "manner")
)

close_vowels <- ipalookup(
  type = "vowel",
  height = "close",
  fields = c("symbol", "frontness", "roundedness")
)

The same API accepts a named list:

ipalookup(
  criteria = list(type = "vowel", frontness = "front"),
  fields = "symbol"
)

7. PHOIBLE features

p <- ipaget("p")
p$features$consonantal
p$features$labial
p$features$nasal
p$features$spreadGlottis

Feature values are usually TRUE, FALSE, or NA. Labels and PHOIBLE features are deliberately separate.

8. Language inventories

english <- ipainventory(iso639_3 = "eng")

for (inv in english) {
  print(inv$inventory_id)
  print(inv$language)
  print(inv$source)
  print(length(inv$segments))
}

Use language, glottocode, or inventory_id when you need a narrower result.

9. Useful flat helpers

ipaget("p", "place")
ipalookup(place = "bilabial", fields = "symbol")
ipavalues("place", type = "consonant", unique = TRUE)
ipaquery("voiced bilabial plosive", fields = "symbol")
